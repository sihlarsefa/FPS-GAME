# HAREKÂT — Sezon Ödülleri (Yalnız Kozmetik)

**Sert kural:** Pay-to-win yok. Para veya sezon puanı ile **güç** alınamaz.  
Kaynak: `Design/GDD/15-monetizasyon.md`.

---

## 1. Ne verilir / ne verilmez

| Verilir (kozmetik) | Verilmez |
|--------------------|----------|
| Kamuflaj, üniforma deseni | Hasar / şarjör / tepme buff |
| Profil nişanı, çerçeve, unvan | Zırh dayanıklılığı |
| Emote / selam animasyonu | Topçu cooldown kısaltma |
| Paraşüt, T-70 / Kirpi boyası | XP güç çarpanı |
| Telsiz tınısı (bilgi avantajı yok) | Bot zorluğu düşürme |
| Mini harita pini, LOD süsü | Loot box ile silah gücü |

Mağaza ve battle pass metinlerinde **“avantaj”** kelimesi yasak; yalnızca görünüm.

## 2. Ödül kanalları

| Kanal | Nasıl kazanılır | Not |
|-------|-----------------|-----|
| Ücretsiz sezon track | XP / görev | Anlamlı kozmetik içerir |
| Lig / turnuva | Sıralama | Şampiyon seti vb. |
| Haftalık etkinlik | Challenge | `takvim_12_hafta.md` |
| Creator drop | Program | `icerik_uretici_programi.md` |
| İsteğe bağlı battle pass (ücretli hat) | Satın alma | Yalnız ekstra görünüm; ücretsiz hat zayıf olamaz |

### 3.2 Lig / turnuva ödülleri

| Derece | Ödül seti |
|--------|-----------|
| Şampiyon | Altın tim çerçevesi + özel şampiyon kamuflaj + unvan “Şampiyon S1” + arazi nişanı |

### 3.3 Haftalık etkinlik (örnek)

Bkz. takvim: Gece nişanı, JNG kamuflaj, Çelik Tim unvanı vb. Hepsi görünüm.

## 4. Nadirlik dilı

| Etiket | Anlam |
|--------|--------|
| Standart | Herkese açık track |
| Kıdem | Lig / yüksek basamak |
| Şampiyon | Turnuva birincisi (ticari satış yok) |
| Arşiv | Sezon bitince mağazadan kalkar; sahiplerde kalır |

**Önemli:** Nadirlik güç değildir. Aynı silah istatistiği.

## 5. Dağıtım ve itiraz

- Ödüller maç / görev doğrulamasından **72 saat** sonra hesabına işlenir (ceza penceresi).  
- Hile DQ → o sezon rekabet ödülleri iptal; ücretsiz track’te kazanılmış kozmetikler politikaya göre kalabilir (exploit ile alındıysa geri alınır).  
- Hatalı drop: destek ticket; kopya item silinir, doğrusu verilir.

## 6. İletişim cümleleri (hazır)

**TR:** “Sezon ödülleri yalnızca görünüm içindir. Silah ve zırh gücü satın alınamaz.”  
**EN:** “Season rewards are cosmetic only. No gameplay power for sale.”
