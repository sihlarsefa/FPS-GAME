### 6.1 Package Manager ile alma/içe aktarma [U: docs.unity3d.com/Manual/upm-ui-import.html]
1. assetstore.unity.com üzerinden Unity ID ile satın alın (iade kuralları: G6).
2. Editör: Window > Package Manager > "My Assets" > paket > Download > "Import x.y.z to project".
3. İçe aktarma penceresinde istemediğiniz öğelerin işaretini kaldırın: içerik paketlerinde (silah, asker, bitki, animasyon) Demo, Scenes, Scripts ve Editor klasörlerini almayın (6.5'te derleme hatası çıkaran eski API'ler ve yalnız-yeni Input System'de çalışmayan `Input.GetAxis` çağrıları çoğu zaman demolardadır). Script'li araçlarda (Altos, Crest, Flora, Kronnect, KINEMATION) tamamını alın.
4. Her paketten sonra §6.2.

### 6.2 Kapı-0 (her paket için)
```
# 1) 6.5+ derleme hatası kaynakları
grep -rIn --include='*.cs' -E 'GetInstanceID|InstanceID|isFileScaleUsed|normalImportMode|optimizeMesh' "Assets/<PaketKlasörü>"
# 2) Render Graph olmayan özel pass (Compatibility Mode 6.4'te kalktı)
grep -rIl --include='*.cs' 'ScriptableRenderPass' "Assets/<PaketKlasörü>" | xargs grep -L 'RecordRenderGraph'
# 3) Eski Input API (projede yalnız yeni Input System açık)
grep -rIln --include='*.cs' -E 'Input\.(GetAxis|GetKey|GetButton|mousePosition)' "Assets/<PaketKlasörü>"
# 4) Batch derleme (tek Unity işlemi kuralı: önce pgrep -x Unity)
/Applications/Unity/Hub/Editor/6000.6.4f1/Unity.app/Contents/MacOS/Unity -batchmode -nographics -quit -projectPath "$PWD" -logFile Logs/claude/<paket>_derleme.log
```
Sonuç temiz değilse: paketi "BEKLE"ye al, satıcıya yaz; yama gerekiyorsa gömülü kopya (§G2 Unity önerisi). Sonra: Render Pipeline Converter (Standard → URP/Lit), `HAREKÂT > Satın Alınan Paketi Bağla`, `BuildWindowsServer` (render paketleri sunucuda `UNITY_SERVER` ile kapalı olmalı), PerfProbe + 4K oto_ekran.
