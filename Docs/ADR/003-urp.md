# ADR-003 — URP seçimi

- **Durum:** Kabul edildi (kesin)
- **Tarih:** 2026-10-06
- **Kaynak:** `Docs/GERCEKCILIK_PLANI.md` v1

## Bağlam

Unity 6.6; 40–60 oyuncu, 1 km harita, orta PC’de 60 FPS. Viewmodel camera stacking mevcut.

## Karar

**URP 17’de kalıyoruz. HDRP’ye geçilmiyor.**

Gerekçe (özet): Unity 2026’da HDRP bakım modunda; yeni GI/SSR yatırımı URP’ye gidiyor;
HDRP taban maliyeti hedef donanımla çelişiyor; stacking HDRP’de sorunlu; ~130k satır
prosedürel URP kodunun göç maliyeti yüksek; asıl darboğaz içerik.

**HDRP yeniden açma:** Yalnızca hedef kitle RTX üst segment + “sinematik ürün” kararı
ve ayrı dalda 14 maddelik kontrol listesi + 2. haftada orta PC 60 FPS kapısı.
