## 1. Kullanım
Dünya prop: dış siluet + girilebilir basit iç (tek oda veya iki). Loot spawner noktaları. NavMesh uyumlu kapı boşluğu.

## 2. Poligon ve LOD
| LOD | Tris |
|-----|------|
| LOD0 | 12–20k |
| LOD1 | 6–10k |
| LOD2 | 3–5k |
| LOD3 | 1–2.5k |

İç mobilya ayrı low-poly set (masa, sandalye) opsiyonel +2–4k.

## 3. Doku
2K atlas: sıva, ahşap hatıl, kiremit. UV1 lightmap. PBR roughness yüksek (mat sıva).

## 4. Pivot / ölçek
Taban köşe veya merkez; Y=0 zemin. Tipik 8×10 m ayak izi, 1–2 kat. +Z “ön kapı dışarı”.

## 5. Modülerlik
Kapı / pencere boşlukları standart yükseklik (kapı ~2.1 m). Variant: dam tipi (kiremit / düz).

## 6. Teslim / kabul
FBX + 2K + collider (mesh veya box birleşimi). İç nav boşluğu. Jenerik “Middle East mudhut” klişesi yok — **Anadolu** taş-sıva-ahşap.

## 7. Referans
İç Anadolu / Karadeniz geçiş köy evi: kiremit, beyaz-krem sıva, ahşap saçak. Foto birebir kopya değil.

## 8. Süre / fiyat
6–10 gün $500–900 · doku $250–450
