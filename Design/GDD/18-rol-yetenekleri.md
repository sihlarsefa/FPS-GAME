# U3. Rol Yetenekleri — Maliyet / Fayda

Ölçek: Fayda 1–5, Maliyet (geliştirme + denge riski) 1–5, Öneri: Şimdi / Sonra / Belki.

- Maliyet: Downed state, animasyon, netcode, zone içinde sonsuz rez riski → rez’de can %30, 1×/oyuncu limiti önerilir.
