# 15. Monetizasyon (Yalnız Kozmetik)

## 15.1 Sert kural

**Pay-to-win yok.** Para ile satın alınamaz:

- Silah hasarı / şarjör / tepme  
- Zırh azaltması veya dayanıklılık  
- Topçu cooldown kısaltma  
- XP çarpanı (güç veren)  
- Bot zorluğu düşürme  

## 15.2 Satılabilir (kozmetik)

| Kategori | Örnek |
|----------|--------|
| Kamuflaj | Üniforma deseni, silah skin |
| Nişan | Kariyer dışı süs nişanı |
| Ses paketi | Telsiz tınısı (bilgi avantajı vermeyen) |
| Emote / selam | Zafer animasyonu |
| Paraşüt / araç boyası | T-70 / Kirpi görünümü |

## 15.3 Kazanılabilir ücretsiz

- Rütbe nişanları (XP)  
- Sezon başarımları  
- Eğitim / poligon rozetleri  

## 15.4 Etik / iletişim

Mağaza metinlerinde “avantaj” iddiası yasak; yalnızca görünüm vurgulanır.  
Battle pass varsa: **ücretsiz hat anlamlı kozmetik** içerir.
