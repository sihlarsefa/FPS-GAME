# Design/UI — Arayüz Mockup’ları (C2-7)

Unity HUD ve menü ajanları için HTML/CSS görsel referans.

## Hızlı açılış

1. `screens.html` — tüm ekranlar, 1920×1080 / 2560×1440 geçişi
2. `StyleGuide.md` — renk, tipografi, boşluk, ikon, animasyon, kontrast
3. `icons/index.html` — SVG ikon seti
4. `prototypes/hud-events.html` — isabet / hasar yönü / komuta animasyonları
5. `ColorBlindness.md` — renk körlüğü notları

## Klasör

```
Design/UI/
  StyleGuide.md
  ColorBlindness.md
  screens.html
  css/          tokens, base, screens, animations, scale.js
  screens/      11 ekran mockup’ı
  icons/        weapons, items, orders, transport, ranks
  prototypes/   animasyonlu HUD
```

Yerel önizleme: dosyayı tarayıcıda açın veya `python3 -m http.server` ile `Design/UI` kökünden sunun (iframe QHD sınıfı için önerilir).
